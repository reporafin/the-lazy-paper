# The Lazy Paper

A cozy, vintage-style digital newspaper designed for a relaxed reading experience. It runs entirely in the browser and features dynamic widgets powered by public APIs and vanilla JavaScript.

**Live Demo:** 

## Features
* **Vintage Aesthetic:** A classic, sepia-toned newspaper layout built with custom CSS grid and SVG illustrations.
* **Evening Broadcast:** A built-in retro radio player streaming live vintage jazz and classical stations directly via the Radio Browser API.
* **Captured Moments:** A vintage photo viewer simulating old camera plates, fetching classic, grayscale photography from Lorem Picsum.
* **Words of Wisdom:** A dynamic section generating classic, aesthetic quotes.
* **Gentle Reminders:** Short, friendly notes promoting physical and mental well-being.

## Built With
* HTML5
* CSS3 (Custom grid layouts and vintage typography)
* Vanilla JavaScript
* Web Audio API & Radio Browser API

## Run Locally
This project requires no build tools, frameworks, or installations. It can be run locally by simply double-clicking the `index.html` file to open it in any modern web browser. 

*Note: For the best experience with the live streaming radio API, running the project through a local development server (such as the VS Code Live Server extension) is recommended to avoid browser security restrictions on audio elements.*
